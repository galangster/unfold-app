Reveal Screen — Final Design

Four layers: scatter-in title, shimmer swipe prompt, draggable curtain lift, haptic choreography

Layer 1: Random Scatter Title (42px)

Reuses the exact RevealChar + shuffleOrder pattern from the welcome screen (src/app/index.tsx).

Font size: 32px → 42px (lineHeight: 50px)
Animation: Each letter fades in (opacity 0→1, 600ms) with white→gold color transition (1200ms)
Order: Shuffled via shuffleOrder() — deterministic pseudo-random per title length
Stagger: 200ms base delay + charOrder[i] * 80ms (faster than welcome screen's 200ms — titles are longer)
Shimmer: Once all letters are placed, a diagonal gradient mask sweeps left→right over 800ms
Eyebrow + day counter: Fade in before/after title (staggered, simple opacity)

Layer 2: Shimmer Swipe Prompt

Position: Bottom of screen with paddingBottom: 40px (down from 60px, still has 6px+ clearance above safe area)
Text: "Swipe up to reveal your devotional"
Shimmer: A soft highlight gradient (accent at 15% opacity) sweeps across the text every 3 seconds using a translating MaskedView + LinearGradient
Chevrons: Two stacked CaretUp icons, each floating with the existing withRepeat timing (-8px, 1200ms). Second chevron delayed 200ms — creates a visual "pull upward" rhythm
Entrance: Fades in ~1.8s after mount (after title completes)

Layer 3: Draggable Curtain Lift

Gesture: Gesture.Pan() tracks translationY on every frame via onUpdate
Drag behavior: Screen translateY follows finger (clamped: only upward, Math.min(0, translationY))
Ambient glow: Existing circle glow moves at 0.3x parallax speed during drag
Threshold: -120px (up from -80px to feel more intentional)
Commit: Past threshold → spring to -screenHeight (critically-damped, damping: 20, stiffness: 200)
Cancel: Released before threshold → spring back to 0
Underneath: Reading screen pre-mounted at opacity 0; fades to 1 as reveal slides away
Navigation: router.replace() fires via runOnJS once spring reaches ~80% of exit

Layer 4: Haptic Choreography

@ -40px drag: Haptics.selectionAsync() — subtle tick, "you're getting close"
@ -120px threshold: Haptics.impactAsync(Medium) — commit point
@ curtain lifts: Haptics.notificationAsync(Success) — the satisfying reward haptic

Haptics fire once per gesture (tracked via shared value flags, reset on gesture start)

Mount Timeline

0ms    Screen fades in, ambient glow appears
200ms  Series eyebrow fades in
500ms  Title letters begin scatter-in (~80ms stagger each)
~1.5s  All letters placed → shimmer sweep across title
~1.6s  Day counter fades in
~1.8s  Swipe prompt + dual chevrons appear
∞     Chevrons float, shimmer loops on prompt text every 3s

User can swipe at any time — animations don't block interaction

What We're NOT Changing

  • Background stays solid colors.background — no pattern overlays
  • Ambient circle glow stays (existing alpha(colors.accent, 0.06))
  • Safe area insets handling stays the same
  • Accessibility label stays, reduced motion skips scatter (shows static title)
