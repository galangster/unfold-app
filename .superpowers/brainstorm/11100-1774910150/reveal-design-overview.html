Reveal Screen — Design Overview

Curtain-lift transition with animated backgrounds, text effects, and haptic feedback

The Five Layers

Each layer adds a distinct sensory dimension. Together they create a moment that feels sacred but not heavy.

1

Animated Pattern Backgrounds

Slowly drifting geometric patterns drawn with Skia — concentric rings, radial dots, or flowing waves. Rotate through 4-5 patterns per series/day (seeded from devotionalId so the same day always shows the same pattern). Subtle accent-colored, ~10% opacity, drifting at 0.5-1px/sec. Calm, not distracting.

Patterns

  • Concentric ripples (expanding rings)
  • Radial dot field (sacred geometry)
  • Flowing sine waves (horizon lines)
  • Soft grid breathing (pulsing intersections)
  • Scattered light particles (existing ember style)
2

Title Text Effect — "Letter Cascade"

Font size bumped to 42px (from 32). Letters animate in with the same MagicalChar pattern from TypewriterText — each character fades in with a slight rise + golden glow that settles to white. Staggered ~25ms per character. A subtle shimmer sweep passes across the completed title once all letters are placed (a diagonal gradient mask moving left-to-right over ~800ms).

3

Swipe Prompt — Lower + Shimmer + Animated Chevrons

Move prompt to bottom 40px (from 60px padding). "Swipe up to reveal your devotional" gets a traveling shimmer — a soft highlight that sweeps across the text every 3 seconds. The single chevron becomes two stacked chevrons with a staggered float animation (second chevron delayed 200ms), creating a visual "pull upward" rhythm.

4

Draggable Sheet + Curtain Lift

The entire reveal screen follows the user's finger as they drag up (translateY tracks gesture). Parallax: background pattern moves at 0.3x speed, content at 1x. Past -120px threshold, the screen accelerates upward (spring to -screenHeight) while the reading screen fades in underneath. The content was already pre-loaded beneath the reveal overlay.

5

Haptic Choreography

Three haptic moments:
(a) Subtle tick at -40px drag (you're getting close)
(b) Medium tick at -120px threshold (commit point)
(c) Satisfying notificationAsync(Success) as the curtain lifts — this is the "reward" haptic that says "you did it."

Timeline: What Happens On Mount

0ms    Screen fades in, pattern starts drifting
200ms   Series eyebrow fades in (uppercase)
400ms   Title letters begin cascading in (~25ms each)
~1.2s   Title complete → shimmer sweep across title
~1.5s   Day counter fades in
~1.8s   Swipe prompt + chevrons appear, begin floating
∞      Pattern drifts, chevrons float, shimmer loops on prompt text

Key Constraints

  • All springs critically-damped (no bounce) per your animation rules
  • Pattern rendering via Skia Canvas (GPU, 60fps, off JS thread)
  • Reduced motion: skip letter cascade, show static title; skip pattern drift
  • Entrance sequence <2s total; no blocking — user can swipe during animation
  • Pattern seeded from devotionalId hash so it's deterministic per day
