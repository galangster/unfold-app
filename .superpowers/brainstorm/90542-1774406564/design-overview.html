Key Behaviors

  • Background audio — plays through tab switches, app backgrounding, lock screen
  • Lock screen controls — play/pause, skip -10s/+10s, scrubber, Now Playing metadata
  • Audio ends — pill shows "Completed" briefly, then auto-dismisses after 3s
  • No X button — all navigation via swipe gestures
  • Pill visible on all tabs — floating above tab bar, consistent position
  • State persists — if user closes app and reopens, pill restores with cached position
