B: Route to Full Sign-In Screen RECOMMENDED

Cons

C: Apple Primary + "More Options" Link

Keep Apple as the main CTA in onboarding (cleanest for iOS users). Add a "More sign-in options" link that navigates to the full sign-in screen for Google/Facebook.

Pros

  • Clean, focused onboarding step
  • Apple is primary (most iOS users prefer it)
  • Still provides all options via link

Cons

  • Google/Facebook users need extra tap
  • Slightly more complex flow
