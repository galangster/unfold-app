# Build 59 — TestFlight Changelog

## New
- **Welcome screen polish**: Subtitle in Instrument Serif italic with word-by-word reveal animation, floating ember particles, warm bottom glow
- **AI-generated mirror-back**: Personalized reflection text generated by AI before devotional starts, with embers animation and staggered scripture reveals
- **Deferred generation**: Background fetch task for overnight devotional generation so next day's content is ready
- **Series finale**: Completion celebration with reflection summary and 11 closure archetypes
- **Scripture anchor tap**: Tappable scripture reference returns to reading position
- **Expanded quote sources**: Broader variety of theologians and thinkers for daily quotes

## Fixed
- **Companion chat performance**: Eliminated streaming lag (500+ re-renders → ~5 per response) via throttled store updates, stable FlatList rendering, and Skia path optimization
- **Journal prompt visibility**: Questions stay visible while writing responses
- **Go Deeper persistence**: SOAP journal saves flush properly on dismiss
- **Apple sign-in logo**: Correct sizing on onboarding sign-in screen
- **Sign-out reset**: Full state reset when user signs out
- **Bridge warning**: Downgraded noisy bridge failure log from error to warn

## Improved
- **Onboarding text**: Left-aligned for better readability
- **Devotional titles**: No longer parrot user's self-description (e.g., "Dad") — uses metaphor and scripture imagery instead
- **Sign-in flow**: Required with no guest option, cleaner layout
- **CompanionOrb**: Static rendering for in-message avatars (animated only in header)
